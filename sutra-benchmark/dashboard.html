Caveats

  • n = 1 run of 5 tickets — a directional demonstration, not a statistical study; agent behavior is stochastic and a re-run would shift exact numbers.
  • Self-referential target — the repo under test is Sutra itself (the only repo both indexed and on disk here). A larger, unfamiliar codebase would likely widen Sutra's lead, since grep's haystack grows while an index lookup stays flat.
  • Reported-tokens formula is opaque — subagent_tokens weights cache vs. fresh tokens in an undocumented way, so 7.6% and 54% are two real lenses on the same run, not a contradiction.
  • Equal-quality is qualitative — both answers were independently correct on the same evidence, but no separate grader scored them.
